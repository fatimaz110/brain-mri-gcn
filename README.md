# Brain Tumor Detection Using AI

### An Energy-Efficient GCN + Transformer Approach

## Project Overview

This project focuses on developing an AI-based brain tumor classification system using MRI images.

It explores a hybrid Graph Convolutional Network (GCN) and Transformer architecture for brain MRI image classification.

## Objectives

- Develop an effective brain tumor classification model.
- Explore GCN and Transformer architectures.
- Improve model generalization on unseen patient data.
- Evaluate model performance using appropriate metrics.
- Explore energy-efficient AI techniques.
- Develop a web application for MRI-based model predictions.

## Classification Categories

1. Glioma
2. Meningioma
3. Pituitary Tumor
4. No Tumor
